# Data Dictionary – DS-A6 Causal Claim and Sensitivity Analysis

## 1. Dataset Overview

The dataset used in this project is `synthetic_tutoring_example.csv`, stored in the `data/` folder.

It contains synthetic student data created for a demonstration of causal analysis. The data is generated using Python and NumPy with a fixed random seed of 6042.

The dataset contains 2,400 observations and 8 columns when generated by the notebook. It is not real student data and does not represent the results of an actual tutoring programme.

## 2. Variables and Definitions

| Variable | Data Type | Description |
|---|---|---|
| `student_id` | Integer | Unique identifier assigned to each student. |
| `prior_score` | Numeric | Student's score before the tutoring intervention. |
| `family_support` | Numeric | Synthetic measure of family support. |
| `tutoring` | Integer (0/1) | Indicates whether the student received tutoring: 0 means no tutoring and 1 means tutoring. |
| `study_hours_post` | Numeric | Study hours measured after the tutoring intervention. |
| `exam_score` | Numeric | Student's exam score, used as the main outcome variable. |
| `pre_treatment_quiz` | Numeric | Quiz score measured before the tutoring intervention. It is used as a negative-control outcome. |
| `engagement_selection` | Integer (0/1) | Indicates whether the student meets the synthetic engagement selection threshold: 1 means selected and 0 means not selected. |

## 3. Main Variables Used in the Analysis

- **Treatment variable:** `tutoring`
- **Main outcome variable:** `exam_score`
- **Pre-treatment covariates:** `prior_score` and `family_support`
- **Post-treatment variable:** `study_hours_post`
- **Negative-control outcome:** `pre_treatment_quiz`

The variable `study_hours_post` is included in a diagnostic regression to examine how the estimated tutoring effect changes when a post-treatment variable is added. It should not be treated as a pre-treatment confounder when estimating the total effect of tutoring.

## 4. Data Generation

The dataset is generated by the notebook if the CSV file does not already exist.

The data generation process includes prior scores, family support, tutoring assignment, study hours, exam scores, pre-treatment quiz scores, and engagement selection.

Motivation is included in the synthetic data generation process but is not stored as a column in the dataset. It acts as an unobserved factor that affects tutoring assignment and student outcomes.

The synthetic data generator uses a random seed of 6042 to make the generated example reproducible.

## 5. Data Quality Checks

The notebook performs the following checks:

- Confirms that all required columns are present.
- Checks that `student_id` values are unique.
- Confirms that `tutoring` contains only 0 and 1.
- Checks for missing values in the required analysis columns.
- Calculates summary statistics for the tutoring and no-tutoring groups.

## 6. Intended Use

The dataset is used to demonstrate:

- Unadjusted and adjusted regression estimates.
- Robust standard errors and 95% confidence intervals.
- Sensitivity analysis for possible omitted-variable bias.
- Outcome distributions and overlap checks.
- Negative-control analysis.
- Causal assumptions and limitations.

## 7. Limitations

This dataset is synthetic and is intended for educational purposes only. The results cannot be used as evidence of the actual effect of tutoring on students.

The analysis illustrates how unobserved confounding, adjustment choices, and causal assumptions can affect the interpretation of regression estimates. The sensitivity analysis uses an assumed bias-shift scenario and is not a universal sensitivity estimator.
